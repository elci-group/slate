  "revised_document": "# Slate\n\nSlate is an **inference clearinghouse and reasoning terminal**.\n\nInstead of using a generate → critique → revise pipeline, Slate:\n\n1. **Fans in** inference from multiple heterogeneous upstream providers.\n2. **Preserves provenance** for each inference (provider, model, timestamp,\n   latency, parameters).\n3. **Normalises** outputs into a common corpus format.\n4. Sends the corpus to **Grok**, a downstream **critical‑reasoning layer**.\n\n> **Inference → aggregation → critical reasoning**\n\n## Architecture\n\n```text\nGroq ──────────┐\nOpenAI ────────┤\nGemini ────────┤──→ Slate ─→ Grok ─→ interpreted conclusion\nOpenRouter ────┤\nOllama ────────┤\nKimi ──────────┘\n```\n\nSlate does not ask Grok to rewrite a draft. It provides Grok with an\naccumulated **inference corpus** and asks it to reason across the corpus.\nThe reasoning covers:\n\n- convergence and disagreement\n- outliers and confidence levels\n- contradictions and corroborations\n- biases, missing evidence, and synthesis\n\n## Quick Start\n\n1. Copy `.env.example` to `.env` and fill in your API keys.\n2. Run a query:\n\n   ```bash\n   cargo run --bin slate -- \"What is the capital of France?\"\n   ```\n\n3. Query a specific provider subset:\n\n   ```bash\n   cargo run --bin slate -- -p groq,gemini --no-reason \"Explain Rust lifetimes\"\n   ```\n\n4. Show the exact corpus prompt sent to Grok:\n\n   ```bash\n   cargo run --bin slate -- --show-prompt \"Is machine learning overhyped?\"\n   ```\n\n## Environment Variables\n\n| Variable | Purpose |\n|----------|---------|\n| `OPENAI_API_KEY` | OpenAI API key |\n| `GROQ_API_KEY` | Groq API key |\n| `OPENROUTER_API_KEY` | OpenRouter API key |\n| `KIMI_API_KEY` | Moonshot Kimi API key |\n| `GEMINI_API_KEY` | Google Gemini API key |\n| `XAI_API_KEY` | xAI Grok API key (downstream reasoning) |\n| `OLLAMA_ENABLED` | Enable local Ollama (any value) |\n| `OLLAMA_HOST` | Ollama base URL (default: `http://localhost:11434`) |\n| `OLLAMA_MODEL` | Ollama model name (default: `llama3`) |\n| `*_MODEL` | Override default model per provider |\n\n## Project Layout\n\n```\ncrates/slate      # Core library: types, providers, engine, reasoning\ncrates/slate-cli  # CLI demo binary\n```\n\n## Key Abstractions\n\n- `InferenceProvider` trait – implemented by every upstream source.\n- `Slate` engine – fans out tasks concurrently and builds a `SlateCorpus`.\n- `SlateCorpus` – a provenance‑preserving collection of inferences.\n- `GrokReasoner` – downstream critical‑reasoning layer over the corpus.\n\n## Status\n\nSlate is an MVP. It supports fan‑in, provenance, normalisation, batching, and\ndownstream reasoning. The following features are out of scope:\n\n- persistence\n- streaming\n- rate‑limit management\n- complex retry policies\n- a REST API"
